# Excel-Data-Consolidation-Dashboard

This project demonstrates Excel-based data consolidation, data quality validation, pivot-table analysis, and dashboard reporting using sanitized datasets.

The goal was to transform raw, inconsistent data into a single, reliable reporting dataset and present insights through structured analysis and an interactive Excel dashboard.

KPI/Dashboard.xlsx

---

## 📌 Project Overview
Organizations often work with fragmented Excel data that requires consolidation before meaningful reporting can occur.  
This project simulates a real-world reporting scenario where multiple datasets are cleaned, standardized, consolidated, and analyzed to support monitoring and decision-making.

The focus is on:
- Data accuracy and consistency
- Transparent transformation steps
- Clear, decision-ready reporting
